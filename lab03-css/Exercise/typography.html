2) Font sizes (different units)

18px – fixed absolute size using px.

1.25rem – relative to root using rem.

1.2em – relative to parent (parent set to 20px).

3vw – scales with viewport width using vw.

clamp(1rem, 2.5vw + .5rem, 2rem) – fluid between min and max.
